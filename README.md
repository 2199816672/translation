# 翻译工具 v1.5.0

基于 PySide6 的桌面翻译工具，支持区域截图 OCR、屏幕实时翻译、麦克风/电脑声音实时字幕、
多语言翻译、文档格式转换、字幕处理与音视频字幕生成。

## 功能

- **区域截图** — 鼠标框选区域；选中后可拖边缘/四角缩放、拖上边中心蓝点（或选区内部）移动，右键/ESC 取消
- **全屏截图** — 一键截取全屏
- **实时翻译** — 框选区域后译文直接叠加显示在选区上，持续自动识别翻译；选区可缩放/移动，适合看视频 / 直播 / 游戏
- **实时字幕** — 麦克风或电脑内部声音实时听写，直接在屏幕下方打开字幕框（无需框选，可拖动 / 四角缩放并记住位置）；原文与译文同步写进主页「识别文本 / 翻译结果」，关掉字幕框也继续识别，直到点「停止实时字幕」；支持原文 / 译文 / 双语、暂停、字号、点击穿透、复制；本地极速模型 / 在线 API / 免费本地服务三种识别来源
- **全局快捷键** — 12 个动作可自定义（截图、实时翻译、实时字幕、停止 / 隐藏 / 暂停字幕、切换显示模式、清空、显示主窗口等），**默认全部为空**，不占用任何按键；窗口最小化到托盘也生效
- **设置搜索** — 设置页顶部搜索框（或 `Ctrl+F`）按关键字即时筛选设置项并自动定位
- **提取文字** — 对截图区域 OCR 识别
- **翻译** — 选区后直接翻译，叠加显示译文；点击切换原文/译文
- **自动翻译** — 开启后选区完成自动翻译，无需手动点菜单
- **OCR 引擎切换** — 支持 Windows 系统自带 OCR 和 EasyOCR，设置页一键切换
- **主页操作** — 提取文字、翻译、复制原文/译文、清除
- **截图编辑** — 选区后点「编辑」：画笔 / 擦除 / 文字；文字可单击或框选一块区域输入，输入后可拖动位置、拖角缩放、双击改字、滚轮调字号，支持撤销 / 重做
- **快捷键** — 默认 `Ctrl+Shift+A` 唤起截图（设置页按键录入，可自定义）
- **7 个翻译 API** — 3 免费 + 4 付费，免费 API 也可填自己的密钥
- **密钥保护** — 设置页 Key / Secret / Token / Cookie 类输入默认密文显示，每个密钥页都有「显示密钥」开关；音视频页与实时字幕的 API 密钥同样不回显
- **文件拖放** — 音视频页支持把音视频文件或整个文件夹拖进来（一次拖多个自动进入批量转录），文档页同样支持拖入
- **智能分段翻译** — OCR 被屏幕宽度拆开的硬换行会自动合并成整句/整段再翻译，
  避免逐行翻译把句子切碎；超长段落按句末标点分块，不会超出免费接口长度限制
- **自动复制** — OCR 完成后自动复制原文或译文到剪贴板
- **错误诊断** — 翻译失败时自动诊断网络问题并给出中文提示
- **系统托盘** — 关闭窗口最小化到托盘，托盘右键可快速截图/恢复/退出
- **开机自启动** — 可设置开机自动启动并最小化到托盘待命
- **自动更新检测** — 启动时静默检测 GitHub 最新 Release，发现新版本给一条可点击提示
- **一键升级** — 应用内直接下载安装包、SHA256 校验、退出后静默覆盖安装并自动重启；也可手动下载 `TranslationTool-Setup-vX.X.X.exe` 双击升级，**配置、密钥、模型、截图全部保留，无需卸载**
- **手动检查更新** — 设置页一键检测，并显示当前版本号
- **文档处理** — 文档/字幕翻译、格式转换、翻译后一键导出目标格式
- **格式转换** — PDF / Word / TXT / 图片 / Excel / CSV 之间互转
- **字幕互转** — SRT · VTT · ASS · LRC 任意互转，翻译保留时间轴
- **中文繁体** — 目标语言支持「中文(繁体)」，繁体源文本选「中文」即转简体
- **音视频字幕** — 选音频/视频文件 → 语音识别生成字幕 → 翻译 → 多格式导出
- **批量转录** — 一次选多个音视频（或直接把文件/文件夹拖进页面），按顺序逐个识别并分别输出字幕；可指定统一输出文件夹，未指定则各自保存在源文件旁；支持总进度、单文件进度、失败跳过、重试失败项、打开输出文件夹、复制全部输出路径
- **AI 润色** — 截图译文、文档译文、音视频字幕（识别后 / 翻译后各一次）一键润色；支持免费公共通道、DeepSeek / 豆包网页版、自定义 OpenAI 兼容 API
- **多种识别模型** — 13 个可下载本地模型（含英文专用 / 蒸馏型号）；按本机硬件智能推荐；支持自有在线 API 与导入本地模型
- **三种导出形式** — 只导出原文 / 只导出译文 / 原文+译文，可选 SRT/VTT/ASS/LRC
- **窄窗口自适应** — 展开侧边导航或缩小窗口时，各页工具栏按功能组自动换行，按钮与下拉框文字始终完整，不会被压成「域截 / 时翻」；宽度充足时仍保持紧凑的一行

## 文档处理（翻译 + 格式转换 + 字幕）

「文档处理」页可加载文档或字幕：**只翻译**、**直接转格式**、或**翻译并转换**（翻译完成自动把译文存为目标格式）。

| 源格式 | 可转换为 |
|--------|---------|
| PDF | Word(docx) / PNG 图片 / JPG 图片 / TXT |
| Word (docx) | PDF / TXT |
| TXT | Word(docx) / PDF |
| 图片 (png/jpg/bmp/gif) | PDF |
| Excel (xlsx) | CSV |
| CSV | Excel (xlsx) |
| 字幕 (srt/vtt/ass/lrc) | SRT / VTT / ASS / LRC / TXT |

说明：
- **Word → PDF** 优先使用本机 Microsoft Word，未安装时自动回退 LibreOffice（两者均无时会给出提示）。
- **PDF → Word** 由 `pdf2docx` 完成；扫描版（图片型）PDF 无法直接转换。
- **字幕翻译**逐条进行并保留时间轴，失败条目保留原文。
- **TXT → PDF** 使用系统微软雅黑字体，支持中文排版。
- 输出文件保存在源文件同目录，命名 `原名_converted.<ext>` / `原名_译文.<ext>`，同名自动加序号。

## 音视频字幕

「音视频」页：选择音视频文件 → 语音识别生成字幕 → 翻译 → 导出。

```
选择文件 → 确认识别模型（本地/在线API/导入） → 开始识别
        → 翻译字幕 → 选择字幕格式 + 导出内容 → 导出字幕
```

**支持的识别方式**

| 方式 | 说明 |
|------|------|
| 本地模型（默认） | faster-whisper，首次使用时页面内一键安装组件 + 下载模型（安装自动轮换 pip 镜像：默认 / 阿里云 / PyPI 官方 / 清华，避免单镜像 403） |
| 在线 API | OpenAI 兼容的 `/audio/transcriptions` 接口（自备地址与密钥，仅允许公网地址）；多数服务限制上传 25 MB，超大文件建议改用本地模型或先提取音频 |
| 导入本地模型 | 选择已有的 faster-whisper（CTranslate2）模型目录，不复制文件 |

**语言选择**：页面上的「音频语言」既是语音识别的语言，也是翻译的源语言。
选「自动检测」时由模型自动判断语音语言，识别完成后状态栏会显示检测结果
（如「自动检测：英语」）；指定具体语言可提高识别准确率。

**可下载模型**（保存在 `~/.cache/trans_asr/models`，支持 hf-mirror 国内镜像；
页面「打开模型目录」按钮可直接定位，也可用「导入本地模型」使用已有模型）

**多语言型号**（中文 / 英文 / 日语等均可识别）

| 模型 | 大小 | 特点 |
|------|------|------|
| tiny | 约 75 MB | 最快，精度一般 |
| base | 约 145 MB | 速度快 |
| small | 约 480 MB | CPU 上速度与精度的最佳平衡 |
| medium | 约 1.5 GB | 精度高，CPU 上较慢 |
| large-v3-turbo | 约 1.6 GB | 高精度且快，有独显时首选 |
| large-v3 | 约 3.1 GB | 最高精度，需要大显存 |

**英文专用型号**（英语内容更快更准，但**无法识别中文**；下拉框中带「仅英文」标记）

| 模型 | 大小 | 特点 |
|------|------|------|
| tiny.en / base.en / small.en / medium.en | 约 75 MB ~ 1.5 GB | Whisper 官方英文版 |
| distil-small.en / distil-medium.en / distil-large-v3 | 约 320 MB ~ 1.5 GB | 蒸馏版，速度可快数倍 |

**智能模型推荐**：进入音视频页后会在后台检测 CPU 逻辑核数、物理内存、NVIDIA 显卡显存
和磁盘剩余空间，结合模型体积给出推荐与理由（例如「无独显 + 16 核 CPU → small」），
点「选用推荐」即可切换，「硬件详情」可查看完整配置。首次使用且未下载任何模型时会自动
选中推荐项；已有选择或已下载模型时只给建议、不覆盖用户设置。

**识别选项（设置 → 语音识别设置）**

| 选项 | 说明 |
|------|------|
| 人声检测 | 默认开启，可跳过静音片段；**歌曲 / 纯音乐建议关闭**（唱歌容易被误判为非人声）。开启时若检测不到人声，会自动改用整段识别重试一次 |
| 检测阈值 | 0.1~0.9，越低越宽松（更容易判为人声），越高越严格 |
| 识别精度 | beam 1（快速）/ 5（标准）/ 10（精确） |
| 实时字幕 | 默认开启：识别过程中每出一段就立即显示；关闭则完成后一次性显示（在线 API 模式不支持） |
| 计算设备 | 自动（推荐）/ 仅 CPU / GPU 加速（需 NVIDIA 显卡） |

**GPU 加速说明**：设置页可一键「检测 GPU」，显示本机显卡型号；选择 GPU 可显著提升
识别**速度**（识别**质量**主要由模型大小决定）。若选择 GPU 但本机不可用（无 N 卡 /
未装 CUDA 驱动 / 显存不足），会自动回退 CPU 并在状态栏提示。

识别过程中状态栏显示「已识别 01:23 / 04:56（剩余 03:33）· N 段」，可随时掌握进度。

简繁输出：音频语言选「中文」时自动输出**简体**（识别时用简体引导语 + zhconv 后转换），
选「中文(繁体)」时自动输出**繁体**。Whisper 本身不区分简繁，默认常输出繁体，因此需要这层转换。

**中文歌识别建议**：关闭人声检测 + 音频语言选「中文」+ 使用 small 及以上模型。

**导出**

- 字幕格式：SRT / VTT / ASS / LRC
- 导出内容：只导出原文 / 只导出译文 / 原文+译文（LRC 双语为「原文 / 译文」单行）
- 输出到源文件同目录，命名 `原名_字幕.<ext>`

### 批量转录

一次要处理一堆音频/视频时，点「**批量转录**」（或把多个文件、整个文件夹直接拖到
音视频页，拖一个仍走原来的单文件流程）：

```
添加文件 / 添加文件夹 / 拖入 → 调整顺序（上移 / 下移）→ 选输出位置
→ 选本次的字幕格式与导出内容（原文 / 译文 / 原文+译文）
→ 需要译文时勾选「同时翻译字幕」→ 开始批量转录
```

- **输出位置**：默认「与源文件同目录」，每个字幕文件保存在对应音视频旁边；
  也可以指定一个统一文件夹，所有字幕集中输出。上次选过的文件夹会被记住，
  但不会自动改变「跟随源文件」这一默认规则。
- **不覆盖**：同名文件自动加序号（如 `讲座_字幕_2.srt`），重复添加的文件自动去重。
- **不中断**：单个文件解码失败、没有语音内容或导出失败，只标记该文件失败并继续下一个；
  结束后可一键「重试失败项」，重试会保留已完成项的记录与输出路径。
- **可停止**：随时点「停止」，当前文件处理完后结束，剩余项标记为已跳过；
  已生成的字幕保留。请求停止后即可关闭窗口（在线 API 单次请求可能较久），
  后台会丢弃剩余项；未点停止时仍不允许直接关窗，避免后台任务失去界面。
- **开始前预检**：识别组件 / 模型 / API 配置、输出文件夹是否可写、
  导出内容与翻译开关是否匹配，都在开始前一次拦下。
- **三种导出内容**（始终由你选，勾选翻译不会把它改成双语）：
  - 只导出原文：转录完直接导出，不调用翻译接口、不产生翻译费用
  - 只导出译文：逐条翻译，字幕里只保留译文
  - 原文 + 译文：逐条翻译，生成双语对照（LRC 为「原文 / 译文」单行）
- **翻译开关**：选中「只导出译文」或「原文 + 译文」时会自动勾上「同时翻译字幕」；
  手动取消勾选会在开始前提示，避免导出「原文冒充译文」的错误字幕；
  勾了翻译但选「只导出原文」时尊重该选择，不调用接口。批量任务使用独立的
  翻译器实例，不会与主窗口的手动翻译互相改语言。单条翻译失败回退原文；
  整份字幕一条都没翻译成功（或翻译引擎整体不可用）时自动退回「只导出原文」，
  不产出「原文 / 原文」的重复双语，也不丢掉已识别的字幕，并在表格状态里说明。
- **结果**：表格逐行显示状态与输出文件名，结束显示「完成 x/y · 失败 n」，
  可一键打开输出文件夹或复制全部字幕路径。

> 批量任务开始时冻结一份当前页面配置（模型、语言、格式、密钥等），
> 运行期间改动页面不会影响已开始的任务。字幕格式与导出内容只在本次批量生效。

## AI 润色

在「设置 → AI 润色」选择通道后，可在以下位置一键润色：

| 位置 | 说明 |
|------|------|
| 截图翻译叠加层 | 翻译完成后菜单出现「润色」 |
| 主页 / 文档处理 | 译文下方的「AI 润色」按钮 |
| 音视频字幕 | 识别结果卡片「AI 润色原文」（识别后）+ 译文卡片「AI 润色译文」（翻译后），两次把关 |

**润色通道**

| 通道 | 说明 |
|------|------|
| 免费公共通道 | 无需密钥，开箱可用；公共通道约 45 秒 1 次，量大或要求更高时建议用下面的通道 |
| DeepSeek 网页版 | 免费（不消耗 API 费用）；需在设置中填入浏览器登录 chat.deepseek.com 后的 `userToken` |
| 豆包 网页版 | 免费；需填入浏览器登录 doubao.com 后的 `sessionid` Cookie |
| 自定义 API | 任意 OpenAI 兼容接口（DeepSeek / 通义 / Kimi / 本地 Ollama 等），可填地址、密钥、模型名 |

获取凭证：浏览器登录后按 F12 → Application/Storage → Local Storage（DeepSeek）或
Cookies（豆包）复制对应值。设置页提供「测试润色」按钮，可先验证通道是否可用。

**只返回正文**：润色提示词要求模型只改错别字、语病、标点和不顺表达，不改变原意、不增删内容；
程序还会清洗模型返回的「润色后：」等前后缀与代码块。字幕批量润色会校验返回条数，
条数不一致时自动逐条重试，确保时间轴与条目一一对应。

## 翻译分段与排版

- **硬换行合并**：上一行没有句末标点（。！？!?…；;）就视为屏幕折行，与下一行合并成整句再翻译；
  空行、行首编号（`1.`、`一、`、`第X章`）会识别为新段落 —— 逐行翻译把句子切碎的问题由此解决
- **结构保持**：段落之间保持原文的空行 / 单换行结构，译文不会多出或少掉空行；
  超长段落按句末标点分块翻译后拼接，不会超出免费接口的长度限制
- **叠加排版**：截图翻译的译文按选区**实际像素宽度**折行，自动在 11 / 10 / 9 号字之间选择，
  仍然放不下时截断并显示「…」，不会溢出选区

## 实时翻译

主页点「实时翻译」（托盘菜单也有）→ 框选一块屏幕区域 → 弹出小菜单点
「开始实时翻译」（或按回车）→ **译文直接叠加显示在选区上**，像截图翻译一样。

- **就地显示**：选区上盖一层半透明深色底 + 白色译文，原文仍隐约可见；
  抓图瞬间会自动把浮层设为全透明、抓完立即恢复，保证识别到的始终是原始画面
- **选区可调整**：拖动选区**边缘 / 四角**改变大小（四角有高亮标记）；
  拖上边中心**蓝色小圆点**或下方**控制条**移动整个选区
- **控制条**：显示刷新速度与上次识别翻译耗时（如「刷新 1.2s/次 · 上次 0.8s」），
  提供 暂停/继续、原文对照、复制、重选、关闭
- **自动刷新**：画面没变化时自动跳过，文字没变化时不重复请求翻译，省资源；
  连续 3 帧识别不到文字才清空译文，避免画面切换时闪烁
- **入口**：主页按钮 / 托盘「实时翻译」；托盘「停止实时翻译」或控制条「×」随时关闭
- 设置 → 实时翻译：刷新间隔（0.8 ~ 3 秒）、是否默认显示原文对照

实时翻译不做 AI 润色，保证刷新速度；识别与翻译引擎与截图翻译一致
（跟随主页「从 / 翻译到」语言设置）。

## 实时字幕

主页底部「字幕音源」选**麦克风**或**电脑内部声音** → 点「实时字幕」→
**直接在屏幕下方出现字幕框，不需要框选**，开始说话或播放视频即可。
字幕框可拖动 / 四角缩放，新位置会被记住，下次启动直接用；
控制条「复位」可回到默认位置。

识别到的原文会逐行写进主页「识别文本」，译文（仅当设置里开启「翻译字幕」）
写进「翻译结果」。**点控制条「隐藏」或按 `Esc` 关掉字幕框并不会停止识别**，
两个文本框仍持续更新；要彻底停止请点控制条「停止」、托盘「停止实时字幕」，
或再点一次主页按钮（运行中会变成「停止实时字幕」）。

**三种识别来源**（设置 → 实时字幕）：

| 来源 | 说明 |
|------|------|
| 本地模型（免费下载 · 离线） | 13 个 faster-whisper 模型；实时推荐 `tiny` / `base`（约 75 / 145 MB），设置页可直接下载 |
| 在线 API（自备密钥） | 任意 OpenAI 兼容 `/audio/transcriptions` 服务，填地址 / 密钥 / 模型名 |
| 免费本地服务（无需密钥） | 指向本机或局域网自建的 whisper.cpp server、speaches 等免费服务，如 `http://127.0.0.1:8000/v1` |

**为什么够快**：模型只加载一次并常驻内存，直接把 16 kHz 音频数组送进
faster-whisper（不落临时文件），`beam_size=1`、关闭 VAD 与上文依赖；
说话停顿约 0.3 秒即切句出字幕，最长 2.5 秒强制出一次；纯静音片段直接丢弃。
翻译走独立线程，网络慢也不会拖慢原文出现。控制条会显示每段识别耗时。

**显示与交互**：

- 字幕显示可随时切 **原文 + 译文 / 仅译文 / 仅原文**（控制条按钮、托盘菜单、设置页三处同源）
- 译文还没回来时先显示原文，不会出现空白等待；翻译失败保留原文
- 字幕框可拖边缘 / 四角缩放、拖控制条移动，位置自动保存（不用每次重选）
- 控制条：暂停/继续、模式切换、`A-`/`A+` 字号、清空、复制、复位、鼠标穿透、隐藏（`Esc`）、停止
- 开启「鼠标穿透」后字幕不挡下面的视频/网页；关闭后才能拖边框调整选区
- 设置页可调：音源、采集设备、识别语言、是否翻译、最长片段、字号、保留行数、底色深浅、穿透

**电脑内部声音**依赖 WASAPI 环回组件 `soundcard`：设置页「实时字幕」分区有
一键安装按钮；系统已启用「立体声混音」时也可以直接选对应设备。
组件未就绪时不会拦死流程，会自动临时改用麦克风并在状态栏提示。

字幕翻译沿用主页「翻译到」的语言；识别语言可在设置页固定（比自动检测更快更准）。

## 快捷键与设置搜索

「设置 → 快捷键」是独立分区，覆盖 12 个动作：区域截图、全屏截图、翻译识别文本、
实时翻译、停止实时翻译、实时字幕、显示/隐藏字幕框、停止实时字幕、暂停/继续、
切换双语/译文/原文、清空当前字幕、显示主窗口。

- **默认全部为空**，不占用任何系统按键；点输入框后按下组合键即可录入，
  按 `Delete` / `Backspace` 或点「清除」清空。
- 全局生效（依赖 `keyboard`），窗口最小化到托盘也能触发；改完点「保存设置」立即生效。
- 同一组合绑到多个功能或已被其它软件占用时会给出提示，换一个组合即可。
- 设置页顶部有搜索框（也可按 `Ctrl+F`），输入关键字即时筛出相关设置行并自动滚到位置。
- 「恢复默认」会把所有快捷键清空，并清空已填的 API 密钥；需要再点「保存设置」才写盘。

应用内所有下拉框都**不会**被鼠标滚轮改变选项（避免滚动页面时误触），
但下拉列表展开后仍可用滚轮浏览长列表。

## 安装、升级与打包

### 给用户：安装与升级

下载 `TranslationTool-Setup-vX.X.X.exe` 双击即可，用户级安装、不弹 UAC，默认装到
`%LOCALAPPDATA%\Programs\TranslationTool`。**升级不需要先卸载**：直接运行新安装包，
或在「设置 → 检查更新」/ 启动提示条里点「立即升级」。

升级会保留：个人配置与密钥（`user_config.json`）、快捷键、截图（`screenshots\`）、
导入的模型（`models\`）、语音识别模型（`%USERPROFILE%\.cache\trans_asr\models`）。
卸载程序也不会删除这些用户数据。

> **从旧 zip 便携版升级请注意**：v1.2.0 及更早发布的是免安装 zip 包，安装程序无法
> 知道你把它解压到了哪里，因此不会自动迁移旧数据。首次安装 exe 后，请手动把旧目录里的
> `user_config.json`（以及 `screenshots\`、`models\`）复制到
> `%LOCALAPPDATA%\Programs\TranslationTool\`。安装版之间的后续升级才会自动保留。

### 给开发者：一键构建

```bash
# 需要 Python 3.11（装齐 requirements）+ PyInstaller + Inno Setup 6
pip install pyinstaller
python build_exe.py            # 只生成免安装程序目录 dist/TranslationTool/
python build_installer.py      # 端到端：重新打包 exe + 编译 setup.exe + 生成 .sha256
python build_installer.py --skip-exe            # 复用上次 exe，只重编安装包（快）
python build_installer.py --portable            # 额外生成免安装 zip
python build_installer.py --version 1.3.0 --skip-exe   # 仅用于本地覆盖升级测试
```

产物在 `dist/installer/`：`TranslationTool-Setup-v<版本>.exe` 和同名 `.sha256`。
版本号唯一来源是 `config.py` 的 `APP_VERSION`，安装脚本通过 ISCC 的
`/dMyAppVersion` 注入，不会多处不同步。

打包使用 onedir，排除 torch / easyocr / CUDA 等超大可选后端（OCR 默认用 Windows
系统自带引擎），随包附带 faster-whisper、ctranslate2、av、sounddevice、soundcard
等常用组件。**安装版不支持在线 pip 安装可选组件**（`sys.executable` 是程序本体），
相关按钮会给出明确提示。

### 发布 Release（让应用内一键升级生效）

1. 把 `TranslationTool-Setup-vX.X.X.exe` 上传到 GitHub Release；
2. 把同名 `.sha256` 文件里的那一行（形如 `sha256:<64位十六进制>  <文件名>`）
   贴进 Release 说明 —— 新版 GitHub API 会直接给出 asset `digest`，这一步是兼容兜底；
3. tag 用 `vX.X.X`，并设为 latest。

`updater.py` 会取 `releases/latest` → 按 `TranslationTool-Setup-v*.exe` 白名单找资产
→ 下载（可取消、显示进度）→ SHA256 校验 → 退出主程序 → 以
`/VERYSILENT /RESTARTAPP=1` 启动安装包。安装脚本的固定 `AppId` 保证识别为覆盖升级，
`[Files]` 的 `Excludes` 保证用户数据不被登记、不被覆盖、卸载时不被删除。
发布方未提供 SHA256 校验值时不会提供一键安装，只会打开发布页让用户手动下载，
避免静默执行一个无法验证来源的安装包；下载响应没有 `Content-Length` 时，
进度条用 Release API 里的资产大小兜底。

### 回归测试

```bash
python -m unittest discover -s tests -v
```

- 核心用例只依赖标准库，Python 3.11 / 3.13 均可跑，不联网、不弹窗、不安装；
- `test_batch_ui.py` / `test_flow_layout.py` / `test_release_fixes.py` 的窗口用例需要 PySide6，未安装时自动跳过；
- `test_flow_layout.py` 覆盖「宽屏一行、窄屏按组换行、控件一个像素都不压缩、标签与下拉框不分离」；
- 本机装了 PySide6 时用 `QT_QPA_PLATFORM=offscreen` 可离屏验证窗口逻辑。
